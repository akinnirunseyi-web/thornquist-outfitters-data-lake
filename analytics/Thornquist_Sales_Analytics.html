Thornquist Outfitters | Sales analytics

August 24–30, 2026

Five business questions answered from Athena query results of thornquist_outfitters.curated_sales.

The AWS pipeline produced 1,601 accepted sales lines. This notebook is an offline analysis of exported results; it does not connect to AWS or refresh automatically. QuickSight access was denied for the Learner Lab role, so the notebook provides the visualization alternative in the team architecture.

To run: keep this notebook beside the six included CSV files. Open it in Jupyter or VS Code with a Python kernel containing pandas and matplotlib, then run all cells. The saved outputs can also be viewed without running code. Monetary figures use source units; the exports do not specify a currency code.

files = {
    'daily': 'Daily sales by source.csv',

    'products': 'Top ten products.csv',

    'stores': 'Store sales ranking.csv',

frames = {key: frame.copy() for key, frame in raw.items()}
for frame in frames.values():
    for column in ['total_sales', 'units_sold', 'transactions', 'pos_sales',
                   'ecommerce_sales', 'identified_customers', 'average_transaction_value']:
        if column in frame:
            frame[column] = pd.to_numeric(frame[column], errors='raise')
daily, regions, products, loyalty, stores = [frames[k] for k in ['daily', 'regions', 'products', 'loyalty', 'stores']]

    return sum((Decimal(value) for value in frame[column]), Decimal('0'))

Data quality context and next decisions The successful Glue run report recorded 400 accepted customers, 1,048 accepted POS records and 226 accepted ecommerce orders. Three POS duplicates and 39 ecommerce orders remained quarantined. Ecommerce rejection reasons overlapped: 35 unknown customer references and five duplicate-order reasons across 39 orders. All 226 accepted ecommerce orders reconciled to their item totals. These figures are contextual values from the verified ETL report, not recalculated from these aggregated CSVs.

A separate controlled test introduced quantity −1 into a copy of order 900000, then restored the original quantity 1. It demonstrated quarantine and promotion without changing production totals. Unresolved production customer references were not assigned guessed customer IDs.

For business follow-up: investigate Atlantic's channel mix; compare availability of leading products across channels; and examine store traffic before treating sales rankings as performance targets.

For refresh: update the upstream Trusted and Curated data, rerun the six Athena queries supporting the five business questions, replace the CSV exports, and rerun the notebook. Current Curated CTAS creation and CSV export are manual. Customer counts by tier are distinct only within each tier; these aggregate exports cannot establish cross-channel customer overlap.
